# 信风 Windpost · 海面、天空与帆船怎么接进游戏

《信风》不再自带水体和船的模型：海面、天空、帆船都来自仓库里的共享模块（[ocean/](../../ocean/README.md)、
[ocean/vessel/](../../ocean/vessel/README.md)），游戏只负责群岛、任务、相机、输入、HUD 和声音，再把这些模块接起来。

| 文件 | 内容 |
|---|---|
| `index.html` | 界面（HUD、菜单、渲染面板、触屏控件）与样式。`<!-- ARTIFACT:BEGIN -->` 到 `<!-- ARTIFACT:END -->` 之间是发布到 claude.ai 的片段，脚本入口是 `<script type="module" src="./main.js">` |
| `main.js` | 游戏代码，`import '../../ocean/...'`。按编号分段：0 小工具、1 IslandField、2 PlanarReflection、3 群岛、4 声音、5 状态与参数、6 天气与海况、7 船、8 任务、9 相机、10 每帧更新、11 HUD、12 菜单与输入、13 主循环、14 启动与测试钩子 |

需要静态服务器打开（ES 模块 + 相对 import）。发布成单文件：`npm run build:windpost`（`tools/build-artifact.mjs` 用 esbuild 把 `main.js` 和它 import 的 `ocean/` 模块打成一个内联脚本，three 仍从 importmap 的 CDN 加载）。

## 1. 用到的模块

| 模块 | 在游戏里做什么 |
|---|---|
| `ocean/Ocean.js` | 海面：`WindSeaModel` 按风速、风区、风时起浪 → GPU FFT（三级级联）→ 着色。白浪场在相机周围的世界坐标里判定破碎、演化泡沫；`setBathymetry` 给岛屿水深（浅滩透出沙底、按水深的破碎带与岸线泡沫、浅水消波）；`setReflection` 叠平面反射；`setWake` 叠尾迹 |
| `ocean/SkyEnvironment.js` | 天空、云、日月星、闪电、反射立方体、PMREM；`applyFog` 给岛、码头、船的材质打上与海面同一个远景雾 |
| `ocean/vessel/` `SailingYacht` | 六自由度帆船：船体水压积分（静水力 + Froude–Krylov）、ITTC / DSYHS 阻力、龙骨 / 舵 / 船体升力、ORC 帆、VPP 式自动调帆、舵机、辅机、触底接触；输出遥测、砰击事件、尾迹源 |
| `ocean/extras/Sailboat.js` | 画面船体。`new Sailboat({ hull: yacht.hull, mastHeight: yacht.options.mastHeight, sky })`：画面与物理是同一组型线参数（浮力、阻力、稳性都按画面上这条船算）；舵跟着物理舵角转 |
| `ocean/vessel/three-adapter.js` | `applyToThree`（位置、四元数、帆的外观）、`emitSpray`（砰击飞溅）、`driveWake`（船行波半角与强度来自兴波阻力） |
| `ocean/WakeMap.js` | 船周围 256 m 的尾迹图（R 泡沫、G 波脊），夜里尾迹发蓝光 |
| `ocean/Spray.js` | `Spray` 飞沫粒子；`SpumeEmitter` 大风（U10 > 9 m/s）时从正在破碎的浪峰撕下飞沫 |
| `ocean/extras/BowWave.js` | 船首浪：Fn > 0.22 后两舷溢出破碎，泡沫注入白浪场（`ocean.addFoam`），船首甩出水片；强度也驱动船首破水声 |
| `ocean/Buoyancy.js` | 浮标漂浮（4 个采样点拟合水面平面 + 二阶阻尼振子） |
| `ocean/CinematicComposer.js` | 后期：HDR → 泛光 → ACES 色调映射 → 调色、暗角、闪电闪光 |

## 2. 每帧的顺序

```
输入 → 控制量（舵角 / 帆脚索 / 油门）
风：平均风 + 阵风 → ocean.model.setWind
yacht.step(dt, { ocean: sea, wind, ground })      // 120 Hz 子步；sea = 海面高度 × 浅水消波，ground = 群岛高度
任务（过门、靠港）、触底与逆风停滞提示
applyToThree → driveWake → wake.update → ocean.setWake → emitSpray → bowWave.update
浮标（Buoyancy）、漂流瓶、目标标记：都取 GPU 回读的海面高度
相机（不低于水面 0.8 m、地面 2.5 m）
sky.update → ocean.update(dt, camera, sky) → SpumeEmitter → spray.update
平面反射（高画质）→ CinematicComposer.render → HUD、声音
```

## 3. 风与浪

- 风是唯一的源头。面板的“风速 / 风向”是 10 分钟平均风 U10；“海况”滑块 ≥ 0.62 起是风暴（风 ×1.8、下雨、打雷、云压满天）。
- `WindSeaModel({ fetch: 150 km, depth: 36 m, timeScale: 20, windResponse: 600 s })`：群岛外的水深 36 m（与 IslandField 一致），
  150 km 风区让信风海况充分发展、风暴受风区限制。
- “海况”滑块另给远方涌浪：Hs = 2.0·s^1.3、周期 9 → 12.5 s，来向比信风偏 25°（36 m 水深按 TMA 衰减）。
- 瞬时风 = 平均风 + 阵风（±10% 风速、±5° 风向，风暴时 ×1.8）。大浪只响应平均风（模型自己做 10 分钟平均），阵风只改变毛细波和猫爪风；帆船吃的是瞬时风。
- 拖动滑块时只改平均风，风浪按生长律慢慢跟上；**松开滑块**（或 `__game.setSea / setWind`）时换上新的涌浪，并 `model.snapWind() → calm() → develop(1) → ocean.resetSea()`，
  直接跳到新风况的极限海况，并丢掉旧的 GPU 回读（否则新旧两个海面的位移差会被当成几十 m/s 的水流，把船打转）。

| 设置 | U10 | Hs（风浪 / 涌浪） | 谱峰周期 | 状态 |
|---|---|---|---|---|
| 默认：信风 14 节、海况 0.3 | 14 kn，4 级 | 1.20 m（1.15 / 0.36） | 5.4 s | 充分发展，浪级 3 |
| 8 节、0.3 | 8 kn，3 级 | 0.52 m | 3.1 s | 充分发展 |
| 20 节、0.3 | 20 kn，5 级 | 1.97 m | 6.7 s | 受风区限制 |
| 风暴：14 节、海况 1 | 25 kn，6 级 | 2.81 m（2.37 / 1.49） | 7.2 s | 受风区限制，浪级 5 |

## 4. 操纵 → 物理

物理全部在 `SailingYacht` 里，游戏只把按键换成控制量。转向快慢、上风舵、低速舵不灵、逆风停滞，都是力平衡的结果，没有脚本写死的转向速率或倾角。

| 操作 | 控制量 | 物理里发生什么 |
|---|---|---|
| A / D、← / →、触屏舵盘 | `setControls({ mode: 'manual', rudder })`：舵角目标 ±30°，舵机 30°/s（`autopilot.rudderRate`），松开回中；D 右转给负舵角 | 舵的升力 ∝ 来流速度²：6.8 kn 时满舵偏航约 17°/s，漂着时几乎转不动。船首转进逆风区后帆抖、减速，舵回中就停在那里（逆风停滞）。本船的上风舵很小（横风约 0.6°），松开舵时 30 s 内只往上风偏约 10° |
| F（或面板“稳舵辅助”） | 松开舵键时 `mode: 'heading'`，目标 = 此刻航向 + 0.6 s 偏航角速度；按键立即交还手操 | `SailingYacht` 的舵机（串级航向 / 角速度控制）替你压住浪和阵风引起的偏航；换了舷会把积分项里的稳态压舵角镜像。默认关 |
| W / S、↑ / ↓、触屏右侧滑条 | `sheet` 0（收紧）… 1（放松），每秒 0.5；从自动切过来时接着当前帆角 | ORC 系数对应最佳调帆；放太松前缘抖帆、升力消失，收太紧分离失速。HUD 的帆角条：青色是当前视风下的最佳位置（与自动调帆同一公式），金色是你的 |
| E | `sheet: 'auto'` | VPP 式自动调帆：最佳横杆角 + 在横倾上限（20°）内挑压平 / 缩帆使驱动力最大；HUD 显示缩帆比例 |
| Shift / 触屏“马达” | `motor: 1` | 辅机推力 1.2 kN（系柱）随航速下降，平静水面全速 5.8 kn；桨后滑流冲到舵上，低速也能转向 |
| X / 触屏“倒车” | `motor: −1` | 倒车推力为正车的 40%：刹船、靠港、脱浅 |
| （自动） | `ground: (x, z) => field.sample(x, z)` | 龙骨、舵、船体 76 个接触点碰到岛的水下地形时，弹簧阻尼 + 摩擦把船停住；冲上沙坡时船首抬起、船倒向一舷躺在龙骨上 |
| R / “请求拖船” | 搁浅后 6 s 还动不了才出现 | 沿地形下坡方向把船拖到水深 8 m 外、船首朝外（游戏层的救援，不是物理） |

换舷全靠船自己的惯性和舵效（14 节风实测）：

- 平静水面按住舵键直到换到新舷 40°：满舵 6.8 s、最低 1.2 节；只打 20° 舵要 9 s，但最低还有 2.1 节、20 s 后回到 6 节。
  满舵时船在弯里侧滑（漂角到 60° 以上），速度反而掉得多。
- 浪里（默认海况）船首对浪、帆又不出力时减速很快（从 5 节滑行 12 s：平静水面剩 3.0 节，Hs 1.15 m 只剩 0.6 节），
  所以迎风换舷常在风眼里停几秒：满舵约 9–13 s 转过去，其间 3–7 s 显示“逆风停滞”，出弯只剩 0.3–0.6 节，要先偏下风把速度跑起来。
- 顺风换舷容易：最低 3.6 节；但舵回中后船还会往上风转（偏航惯性加上低速时帆的力矩），要反打一点舵。
- 逆风停滞超过 2 s 时提示脱困办法（舵打到底等风把船首压开，往后退时舵是反的；或开马达）；目标在上风时 HUD 提示走之字形。

靠港取信 / 送信：在码头外的光圈（半径 20 m）里对水速度（`telemetry.speed`）低于 3 节并保持 1 秒。减速的办法和真船一样：转向迎风让帆抖、放松帆脚索、倒车刹住。

奖章时限（金章 = 估计用时，银章 1.35 倍）按当前风况估计。极曲线是默认海况里在游戏中实测的稳态船速
（稳舵辅助保持航向，每个角度平均 20 s；与 node 里同样浪高的不规则浪对照）：

| 真风角 | 40° | 50–52° | 60° | 75° | 90° | 110° | 135° | 160° | 180° |
|---|---|---|---|---|---|---|---|---|---|
| 游戏里（Hs 1.2 m） | 3.0 | — | 5.4 | 6.0 | 5.7 | 6.1 | 5.8 | 4.9 | — |
| node 不规则浪（Hs 1.15 m 风浪 + 0.36 m 涌浪，3 个种子） | 3.6 | 5.0 | 5.7 | 6.3 | 6.6 | 6.4 | 5.8 | 5.2 | 5.3 |
| 平静水面 | 6.0 | 6.5 | 6.7 | 6.8 | 6.8 | 6.5 | 5.9 | 5.4 | 5.3 |
| 时限用的表 `POLAR_SEA` | 3.2 | 4.8 | 5.45 | 5.9 | 5.9 | 6.0 | 5.7 | 4.9 | 4.9 |

浪里最佳迎风角约 52°（VMG 3.0 节；平静水面是 40°、4.6 节）。风速按 (U/14)^0.55 缩放；目标在最佳迎风角以内时按该角的 VMG 走之字形，
每 400 m 加 20 s 换舷，再乘 0.85 的余量。五封信的金章时限：灯塔岛 → 椰影岛（437 m，真风角 24°，要走之字形）6:18、椰影岛 → 渔村岛 4:11、渔村岛 → 月湾岛 9:54、
月湾岛 → 石门岛 5:57、石门岛 → 灯塔岛 6:15；环岛赛 7:52（旧时限按平静水面极曲线算，第一封信只有 4:09，浪里几乎拿不到金章）。

HUD：罗盘船首朝上，青色箭头 = 真风（`telemetry.twa`），白色 = 视风（`telemetry.awa`），红色扇区 = 真风来向 ±35°（停滞时变深），金色 = 横杆，红色短线 = 舵角；
读数是对水速度（后退时带负号）、横倾、舵角、马达 / 倒车；航向角名按 |真风角|：< 35° 逆风（低于 2 节且没开马达时“逆风停滞”）、< 62° 迎风、< 118° 横风、< 152° 侧顺风、其余顺风。

## 5. 天空、光照单位、后期

选了 `SkyEnvironment` 而不是保留游戏自己的天空：
- **单位对得上**：`keyLightColor` 是白色漫反射面在该光下的亮度（E/π，正午 ≈ 1），`Ocean.update` 自己乘 π 变成辐照度；`ambientColor` 由 GPU 探针从反射立方体积分后读回，与海面反射的天空完全一致。旧天空的主光是手调的 ×3.6、环境光是解析近似，海面着色器换了以后量纲对不上。
- **外观一样**：它本来就是从《信风》的天空抽出来的 —— 同样的 Preetham 补丁（夜空、月晕、风暴变灰、立方体里不画日面）、同一个太阳轨迹和 Kasten–Young 消光、同样的星星和月亮。12 分钟的昼夜（`S.hours` → `timeOfDay`，黄昏放慢、深夜加快）和风暴（`S.storm` → `storm`）照旧由游戏驱动。
- 另外得到：云遮太阳时直射光减弱、闪电（有方位和距离，雷声按距离 / 343 m/s 延迟、越远越轻）、`applyFog` 统一的远景雾。

后期用 `CinematicComposer`，参数取旧版的值：ACES、曝光 0.5、泛光 0.55（阈值 2.4），饱和 1.12、暗角、很轻的颗粒；闪电时 `params.flash` 闪一下（减少动态效果时减弱）。

## 6. 群岛、水深、漂浮物

- `IslandField` 仍是解析的岛屿高度函数（月牙湾、礁盘、珊瑚礁噪声），烘焙成 1024² 半精度纹理：`ocean.setBathymetry(texture, (min, min, size, size))`。
  海面因此有浅滩颜色（沙底按水深透出）、按水深的破碎带和岸线泡沫、浅水消波。CPU 侧 `sample()` 与 GPU 同样的双线性插值，给船的触底、相机、小地图用。
- 船和浮标看到的海面 = `ocean.sampleHeight`（GPU 回读，延迟 1–2 帧）× 与海面顶点着色器相同的浅水消波 `smoothstep(0, 4, 水深)`，所以浅滩上船不会被画面上已经消掉的浪抬起来。
- 浮标：每个一个 `Object3D` + `ocean/Buoyancy`（升沉周期 1.3 s），写到实例化网格；漂流瓶、浮标门引导线、码头光圈都放在回读的水面高度上。
- 平面反射：游戏自己的 `PlanarReflection`（斜近裁剪面镜像相机，半分辨率，只画船、岛、码头）→ `ocean.setReflection(rt.texture, textureMatrix, 强度)`，只在高画质开。

## 7. 渲染面板（T）

| 面板 | 对应 |
|---|---|
| 海况 / 风向 / 风速 | 涌浪与风暴 / 平均风（见第 3 节；松开时海况跳变） |
| 浪尖 | `ocean.params.choppiness`（水平位移系数，1 = 线性理论） |
| 白浪 / 泡沫寿命 / 猫爪风 | `params.foamAmount` / `foamLifetime` / `gustiness` |
| 深水色 / 沙底色 / 透光色 / 透光强度 | 材质 `uDeepColor` / `uSand` / `uSSSColor` / `uSSS.x`（浪尖透射，乘 `OCEAN_LOOK.sss.x`） |
| 夜光藻 | `params.biolumination`，默认 2（乘以 `sky.night`；尾迹和碎浪发蓝光，飞沫也带一点蓝。真实航速下船尾泡沫比旧版少，所以默认比模块的 1 亮） |
| 天空反射 / 倒影强度 / 平面反射 | `params.envIntensity` / `setReflection` 的强度与开关 |
| 时刻 / 时间流速 / 云量 / 雾 | 游戏时钟、`sky.update` 的 `cloudCover`、`sky.fogDensity`（海面雾跟随它） |
| 曝光 / 泛光 | `CinematicComposer.params.exposure / bloomStrength` |
| 稳舵辅助 | 见第 4 节 |
| 调试视图 | `ocean.setDebugView`：法线、泡沫、粗糙度、菲涅尔、尾迹、水深、阵风、白浪场；“线框”= `ocean.material.wireframe` |
| 画质 | `ocean.setQuality` 等（见第 8 节） |

去掉的旧参数：细节法线（FFT 海面有真实的毛细波与亚像素坡度方差，换成“猫爪风”）、高光强度（太阳闪光带由 Cox–Munk 粗糙度决定）、浅水色（浅滩颜色 = 透过吸收的沙底，换成“沙底色”）、波峰尖锐（换成“浪尖”）。
参数存在 `localStorage` 的 `windpost.params2`（旧版的值含义不同，不再套用）。

## 8. 画质

| | 高（桌面默认） | 中（触屏默认） | 低 |
|---|---|---|---|
| FFT / 级联 | 256² × 3（2048 / 160 / 24 m） | 128² × 3 | 64² × 3 |
| 白浪场 | 1024²，512 m | 512²，384 m | 256²，256 m |
| 海面网格细格 | 0.45 m | 0.8 m | 1.6 m |
| 像素比上限 / MSAA | 1.5 / 4× | 1.25 / 无 | 1 / 无 |
| 阴影 / 平面反射 | 2048² / 半分辨率 | 关 / 关 | 关 / 关 |

标题页按钮、Q 键、面板都能切换（高 → 中 → 低），`ocean.setQuality` 重建模拟与网格、保留风浪状态和外观参数。天空立方体（256² / 128²）、尾迹图（512² / 256²）、岛屿网格密度在启动时按设备定好。
一帧的绘制调用约 140 次、约 145 万三角形（含平面反射与阴影两遍）。

## 9. 测试钩子

`window.__game`：`debug()`（模式、船速、航向、真 / 视风角、横倾、舵角、油门、触底、Hs、白浪覆盖、绘制调用……）、`freeze(on)` / `render(dt)`（冻结主循环、按需渲染一帧）、
`step(n, dt)`（不渲染推进 n 帧，每 4 帧同步一次 GPU）、`setSea / setWind / setTime / setQuality / setParam`、`teleport(x, z, 罗经方位, 节)`、`setControls`、`completeGate / arriveDock`、
`depth(x, z)`（群岛水深）、`pars()`（五封信的距离、真风角、金章时限）等。

```bash
node tools/play.cjs games/windpost/index.html out/windpost tests/smoke.cjs --root=.
node --test tests/ocean/vessel.test.mjs        # 帆船动力学（含辅机、触底）14 项
```

## 10. 去掉了什么

旧版单文件里自带的这些都删了，由上面的模块代替：

- `OceanWaves`（14 个 Gerstner 波）、自写的海面网格与着色器、细节法线 / 泡沫 / 焦散纹理、自写的 `WakeMap`；
- `SkyEnv`（Preetham + 云 + 星月 + 立方体）与 `patchFog`；EffectComposer 手搭的后期；
- `HullGenerator` / `createBoat` / `Buoyancy`（弹簧点浮力）/ 点精灵浪花；
- 极曲线 `POLAR` 与 `sailPhysics`：写死的航速系数、转向速率 ∝ 船速、“目标倾角”、按坡度把船推开的搁浅。

行为上的变化：船速是真实的（14 节信风横风约 6 kn，平静水面 6.8 kn，旧版约 13 kn；浪里迎风只有 3–5 kn），所以任务时限按实测极曲线重算、环岛赛纪录换了存储键（`windpost.raceBest`）；
靠港要减速到 3 节以下（旧版的阈值约 7 节）；浅滩没有焦散了（新海面着色器没有焦散项）。

## 11. 已知问题

- 浅水消波只在游戏这边对回读高度做了（`Ocean.sampleHeight` 本身不知道水深）；水质点速度同样按比例缩小，是近似。
- 搁浅很深时倒车也可能退不出来（船倒在龙骨上），这时用“请求拖船”。
- 浪里迎风慢、换舷难，是 `SailingYacht` 的行为，游戏没有改它（只加了提示、按实测船速定时限）：哪怕 Hs 0.37 m / 2.5 s 的小浪，
  真风角 52° 的船速也从 6.5 掉到 4.1 节，`telemetry.resistance.radiation` 约 290 N（平静水面总阻力 970 N）；
  模块自带的舵机换舷（7°/s）在 Hs 1.15 m 里 4 次有 2 次转不过去。满舵（≥ 25°）转弯时船体侧滑（漂角 40–75°）。
- 真机帧率没测过：只在软件渲染下验证了流程与画面。
